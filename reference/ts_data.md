# Simple Time-Series Data

Simulated Time-Series Data (from
[`mlts_sim`](https://munchfab.github.io/mlts/reference/mlts_sim.md)) for
two time-series variables.

## Usage

``` r
ts_data
```

## Format

### `ts_data`

A data frame with 1,100 rows and 4 columns:

- ID:

  Unit identifier

- time:

  Time point

- Y1, Y2:

  The two time-series variables

## Source

[`mlts_sim`](https://munchfab.github.io/mlts/reference/mlts_sim.md)
