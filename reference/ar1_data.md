# Simple Time-Series Data

Simulated Data (from
[`mlts_sim`](https://munchfab.github.io/mlts/reference/mlts_sim.md)) for
one time-series variable.

## Usage

``` r
ar1_data
```

## Format

### `ar1_data`

A data frame with 2,500 rows and 3 columns:

- ID:

  Unit identifier

- time:

  Time point

- Y1:

  The time-series variable

## Source

[`mlts_sim`](https://munchfab.github.io/mlts/reference/mlts_sim.md)
